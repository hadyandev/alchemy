
## 📡 Data Strategy: The Hybrid Alchemist
- **Notion (The Brain):** Acts as the Source of Truth.
- **CI/CD (The Transmutation):** Data is fetched from Notion during the build process on Netlify/Cloudflare.
- **Static Output (The Result):** The final website is 100% static, ensuring lightning-fast performance while displaying the latest Notion data from the last build.
